# Структура календаря

Открывайте `index.html`. Он сохраняет тот же внешний вид, авторизацию Supabase и формат данных, что и версия в одном файле.

## Стабильное ядро

- `core/config.js` — подключение к Supabase и общее состояние приложения;
- `core/auth.js` — вход и выход через Google/Supabase;
- `core/state.js` — тема, popover-окна, загрузка и сохранение данных.

Эти файлы не нужно менять при обычных доработках интерфейса календаря.

## Компоненты календаря

- `features/calendars.js` — вкладки, создание, переименование и удаление календарей;
- `features/colors.js` — палитра, названия и легенда цветов;
- `features/year.js` — годовая сетка и отметки дней;
- `app.js` — запуск приложения после загрузки всех компонентов.

Стили и разметка остаются в `index.html`, чтобы визуальное оформление было в одном месте.
